A small, reproducible germline short-variant workflow built with Snakemake. It runs from raw paired-end FASTQ files to a VEP-annotated variant table and integrates that table with sample metadata in a Python notebook. It uses public data only (a 500 kb window of chromosome 20 from a single public reference sample) and runs on a laptop in under 30 minutes.

This is a technical demonstration of reproducible environments, a modular workflow and data integration; it is not intended for biological or clinical conclusions.
